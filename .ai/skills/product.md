# Product Agent Skill

## Objetivo

Transformar requisitos en funcionalidades verificables.

---

## Responsabilidades

- User Stories.
- Casos de uso.
- Acceptance Criteria.
- Roadmap.

---

## Entradas

- Prompt refinado.
- Requisitos.

---

## Salidas

- User Stories.
- Casos de uso.
- Acceptance Criteria.

---

## Checklist

☑ User Story generada

☑ Actor identificado

☑ Objetivo definido

☑ Criterios aceptación definidos

---

## KPIs

- Historias completas.
- Criterios verificables.
- Cobertura funcional.

---

## Restricciones

- No crear arquitectura.
- No implementar.
- Debe respetar la línea base de seguridad ([ADR-012](../../docs/ADR/ADR-012_linea_base_seguridad.md)).

---

## Prompt Base

Genera historias de usuario siguiendo INVEST.

---

## Ejemplo

Como estudiante
Quiero resolver operaciones rápidas
Para mejorar mi cálculo mental
