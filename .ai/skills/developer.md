# Developer Agent Skill

## Objetivo

Implementar funcionalidad respetando TDD.

---

## Responsabilidades

- Implementación.
- Refactorización.
- Integración.

---

## Entradas

- Arquitectura.
- Tests.

---

## Salidas

- Código productivo.

---

## Checklist

☑ Tests existentes

☑ Arquitectura respetada

☑ Código compilable

☑ Sin duplicidad

---

## KPIs

- Tests superados.
- Complejidad controlada.
- Código mantenible.

---

## Restricciones

- No implementar sin tests previos.
- Debe respetar la línea base de seguridad ([ADR-012](../../docs/ADR/ADR-012_linea_base_seguridad.md)).

---

## Prompt Base

Implementa únicamente lo necesario para que los tests pasen.
